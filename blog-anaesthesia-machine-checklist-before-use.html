Anaesthesia Machine Checklist: What to Check Before Every List

Checking the anaesthesia machine before use is a simple way to keep patients safe. This guide lists the checks the UK Association of Anaesthetists recommends, when to do them, and what to do if the machine fails.

PBy Pulse Team · Updated November 21, 2026 · 4 min read
Share

Check the anaesthesia machine at the start of every theatre session and before each new patient. Confirm power, gas pipelines and cylinders, test the oxygen failure alarm, check vaporisers, do a breathing system leak test and two-bag test, and check the ventilator, scavenging, suction, monitors and airway kit. A self-inflating bag must always be at hand.

When to Check

  • At the start of every theatre list, and again if the anaesthetist changes.
  • Before each new patient, and when any part is changed.
  • After any serious incident, even if the machine was checked earlier.
  • Once a week, test the oxygen failure alarm and note it in the logbook.

These timings come from the 2012 guideline on checking anaesthetic equipment from the UK Association of Anaesthetists (then AAGBI).

Always Have a Backup

A self-inflating bag must be close at hand wherever anaesthesia is given, along with a spare oxygen source. Staff should also know what the machine does if it fails. Some machines fall back to little or no gas flow, or to oxygen with no anaesthetic. So there must be another way to give oxygen, breathe for the patient and keep them asleep.

Training Comes First

The guideline says no one should use the equipment unless they are trained and able to use it. Some machines run a self-test when switched on. We suggest treating the self-test as one part of the check, not the whole check, and following the maker's list for your model.

Monitoring Matters

The CO2 monitor is one of the most useful checks. It helps show the tube is in the airway and the patient is breathing. See our EtCO2 and capnography and patient monitor normal values guides.

Anaesthesia Machine Checklist: Key Facts

  • Check the machine at the start of every list and before each new patient.
  • Test the oxygen failure alarm weekly and record it in the logbook.
  • Pipeline gauges should read 400 to 500 kPa; do a tug test on each pipeline.
  • Do a breathing system leak test and a two-bag test before use.
  • Keep a self-inflating bag and spare oxygen close at hand.

Anaesthesia Machine Checklist: FAQs

How often should an anaesthesia machine be checked?

At the start of every theatre list, before each new patient, after any serious incident, and when a part is changed. Test the oxygen failure alarm each week.

What is the two-bag test?

A final check of the whole breathing system with a test lung or second bag, done after the breathing system, vaporisers and ventilator have each been checked.

What should pipeline gas pressure be?

The UK guideline says pipeline gauges should read 400 to 500 kPa. Do a tug test on each pipeline to make sure it is firmly connected.

How long should the oxygen failure alarm sound?

For at least 7 seconds. Staff should also know which gases keep flowing when oxygen fails.

What backup is needed if the anaesthesia machine fails?

A self-inflating bag and spare oxygen must be close at hand, with another way to keep the patient asleep.
